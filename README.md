# Pizza Sales Analysis using SQL & Power BI

## Project Overview
This project focuses on analyzing pizza sales data using SQL and Power BI to understand business performance, sales trends, and product popularity.

## Tools & Technologies
- SQL
- Microsoft Power BI
- DAX
- Data Visualization

## Key Performance Indicators (KPIs)
- Total Revenue
- Average Order Value
- Total Pizzas Sold
- Total Orders
- Average Pizzas Per Order

## Dashboard Analysis
- Daily and hourly order trends
- Sales distribution by pizza category
- Sales distribution by pizza size
- Total pizzas sold by category
- Top 5 and Bottom 5 pizzas based on revenue, quantity, and orders

## Project Files
- SQL Queries
- Power BI Dashboard (.pbix)

## Project Objective
To analyze pizza sales performance, identify purchasing trends, and generate meaningful business insights through interactive visualizations.
